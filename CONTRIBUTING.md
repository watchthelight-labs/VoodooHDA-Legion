# Contributing

Useful reports: other Arrow Lake laptops with an `8086:7F50` controller (which codec, which VoodooHDA layout worked, `system_profiler SPAudioDataType`), and results for the parts marked untested in the README (microphone in a call, headphone jack, volume keys). The bound-check hunks of `legion.patch` belong upstream in VoodooHDA; if you send them there, say so here so the patch can shrink.

Pull requests: small, with the machine and macOS build you tested on. AI-assisted PRs are fine as long as you can explain the change, which is the same bar I hold my own code to.
